- (assumption) Starter propuesto y verificado: Python 3.13.16, Django 5.2.8 LTS y Playwright Python 1.63.0; el usuario aún debe aceptar esta selección.
- (decision) Paradigma modular monolith con límites hexagonales: domain no depende de Django, application orquesta casos de uso, infrastructure adapta persistencia/reloj y web adapta HTTP/templates; previene reglas duplicadas entre F4 y F1.
- (decision) F4 es un servicio de dominio puro y determinista sin IO ni reloj; previene que interfaz, persistencia o pruebas produzcan resultados distintos.
- (decision) Toda mutación pasa por application y compara Version del caso esperada con vigente dentro de una transacción; conflicto devuelve stale_version y no escribe; previene sobrescritura de Decisiones.
- (decision) Evaluaciones, Decisiones y Correcciones son registros append-only; una Corrección referencia original y corregido y una Discrepancia no muta la Decisión; previene pérdida de procedencia.
- (decision) Política es inmutable por versión y cada Evaluación copia parámetros efectivos; previene reinterpretación retroactiva.
- (decision) Plazos consumen un Clock y BusinessCalendar inyectables con America/Santiago y lunes a viernes; previene pruebas dependientes del reloj real.
- (decision) Casos controlados y Evidencia ficticia viven como fixtures versionados del repositorio y se cargan idempotentemente; previene demos divergentes y datos sensibles.
- (decision) La web es server-rendered con mejora progresiva mínima; el DOM y la respuesta del servidor conservan Evidencia y razones antes de Puntaje; previene divergencia entre cliente y servidor.
- (decision) SQLite es el store local del incremento y las escrituras usan transacciones cortas más control optimista; previene dos dueños de estado sin añadir infraestructura productiva.
- (decision) Errores cruzan límites como códigos estables y contexto seguro; logs usan IDs de Caso/Versión/Política y nunca contenido de Evidencia ni secretos.
- (decision) La entrega opera como un único proceso local y una base local; despliegue productivo, auth y servicios externos quedan fuera del incremento.
